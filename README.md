## Getting Started

### Requirements

- [Unity Hub](https://unity.com/download)
- Unity Editor (use the version listed in `ProjectSettings/ProjectVersion.txt`)
- [Git](https://git-scm.com/) and [Git LFS](https://git-lfs.com/)

### Setup

1. Install Git LFS (one time only):
   ```
   git lfs install
   ```
2. Clone the repository:
   ```
   git clone https://github.com/KhayelihleNcama/THESEVENTHLIFEE.git
   ```
3. Open **Unity Hub**, click **Add > Add project from disk**, and select the cloned folder.
4. Open the project with the matching Unity version and wait for the first import to finish.
5. Open `Assets/Scenes/SampleScene.unity` and press **Play**.
